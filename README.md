# Teller – Kalorien & Wochenplan (PWA)

Mobile Web-App auf Deutsch: Kalorien und Makros im Blick behalten, Mahlzeiten erfassen (Open Food Facts, Barcode-Scan),
Rezepte, Wochenplaner und Einkaufsliste. Installierbar über „Zum Startbildschirm hinzufügen“.

> Die vollständige Dokumentation (Setup, Deployment, Annahmen) folgt mit Abschluss aller Phasen.

```bash
npm install
cp .env.example .env   # Supabase-Zugangsdaten eintragen (optional – ohne gibt es den lokalen Demo-Modus)
npm run dev
npm test
```
